# Build a Premium Landing Page for Dawson Landscaping & Maintenance

Create a completely custom, modern, premium landscaping company landing page for **Dawson Landscaping & Maintenance**, a Perth-based landscaping and garden maintenance business.

The goal is NOT to create a generic landscaping template.

The goal is to create a **high-end, conversion-focused landscaping website** inspired by the visual quality, cleanliness, image composition, spacing, and interactive feel of the attached reference website, while creating a completely original layout and visual identity for Dawson Landscaping.

Use the **attached Dawson Landscaping logo files** as the primary brand identity. Do not redesign, distort, redraw, or replace the logo.

The final result should feel like a website that could realistically be launched for a premium Perth landscaping company.

**Aesop-level simplicity + premium Australian landscaping photography + modern conversion-focused UX + organic Dawson branding.**

The first impression should be:

> "This company is professional, established, trustworthy and worth contacting."

Do not fill every section with content.

Every section should answer at least one of these questions:

1. Who is Dawson?

2. What services do they provide?

3. Can they do quality work?

4. Can I trust them?
